# README

This project is designed for exported files from FootPrint, which is a position recording app.

To try on this visualization, you can use the backUpData.csv to have a brief look, or use your own position data.

You may need to install all the dependencies first.

```bash
npm install
```

To run this website.

```bash
npm run dev
```

Then upload csv file on imported page, you can see the analyses in calculate and personal page.
